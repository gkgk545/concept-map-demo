# 비교는 방향 없는 개념 짝으로만 하고, 관계 문장은 채점하지 않는다

서버도 AI도 없어 관계 문장의 옳고 그름을 판정할 수 없다. 그래서 맞은 연결은 '선생님 개념도에 같은 개념 짝이 있는가'로만 정한다. 화살표 방향과, 선생님 쪽이 선수 학습 연결인지 관계 연결인지는 따지지 않는다. 문장은 비교 화면에서 선생님 문장과 나란히 보여 주어 학생이 스스로 점검하게 한다.

달성도는 맞은 연결 ÷ 선생님 개념도의 개념 짝 수이고, 내가 더한 연결은 감점하지 않는다. 대신 모든 짝을 이어 달성도를 올리는 일을 막으려고 관계 문장을 필수로 하고, 달성도와 놓친 연결은 학생이 [비교] 버튼을 누를 때만 갱신한다(실시간으로 바뀌면 하나씩 이어 보며 정답을 찾아낼 수 있다).
