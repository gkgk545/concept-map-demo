# 서버 없이, 내 개념도는 학생 브라우저에만 둔다

학생 개인정보를 받지 않기 위해 서버·로그인·제출 수합 기능을 두지 않고, 정적 파일만 Cloudflare Pages에 올린다. 내 개념도는 그 브라우저에 단원별로 자동 저장하고([처음부터]로 지운다 — 학교 공용 PC 대비), 선생님에게 낼 때는 PNG로 저장해 학생이 기존 수업 도구(패들릿, 클래스룸 등)에 직접 올린다. 그래서 선생님이 반 전체 결과를 한곳에서 모아 볼 수는 없다 — 이건 의도한 한계다.

## Consequences

- 브라우저 데이터를 지우거나 다른 기기로 옮기면 내 개념도는 사라진다.
- 선생님 개념도는 `data/`의 JSON을 직접 고쳐 만든다. 앱 안의 편집 화면은 없다.
